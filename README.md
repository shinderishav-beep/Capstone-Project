# Capstone Project — *Be Yourself*

A videogame built around the central theme of **identity and self-acceptance**.

## About the Game

*Be Yourself* is a narrative-driven videogame that challenges players to explore what it truly means to embrace who they are. In a world that constantly pressures people to conform, the game invites players on a journey of self-discovery — making choices that reflect their authentic values, confronting doubt and external expectations, and ultimately finding the courage to simply be themselves.

## Theme

The game's core message is rooted in the idea that **authenticity is strength**. Every mechanic, story beat, and character interaction is designed to reinforce that message — rewarding players not for being the most powerful or popular, but for staying true to themselves.

## Goals

- Create an emotionally resonant gameplay experience centered on identity
- Use game mechanics to reflect the real-world tension between conformity and authenticity
- Tell a story that feels personal and relatable to a wide audience

## Status

This project is currently in development as part of a Capstone course.
